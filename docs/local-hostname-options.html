1. Background: how names become addresses

Browsers connect to IP addresses, not names. When you type a name, your device has to resolve it to an address first. It tries several methods, roughly in this order:

  1. The hosts file on the device itself.
  2. DNS — it asks the DNS server it was given by the router (usually the router itself, which forwards to your internet provider).
  3. Multicast methods on the local network — mDNS for names ending in .local, and on Windows also LLMNR and NetBIOS for single-word names.

Every option in this guide just makes one of those methods answer “cydnet is 192.168.4.27”. The difference is who answers: the CYD itself, your router, a separate DNS server, or a file on each computer.

2. Why localhost is different

localhost is reserved to always mean “this same machine” (address 127.0.0.1). Every operating system answers it internally without asking the network, which is why it works with no setup. It can never point at another device such as the CYD, so there’s no equivalent to set up — you need one of the options below.

Names are case-insensitive. CYDNet, cydnet, and CYDNET are the same name.

4. Option 1: mDNS (cydnet.local) Easiest, no equipment

Multicast DNS lets a device answer for its own name. When a phone looks up cydnet.local, it sends a question to everyone on the local network, and the CYD replies with its address. Apple calls this Bonjour; it’s also how printers and smart speakers are discovered.

What it would take

The ESP32 Arduino core includes an ESPmDNS library. After the CYD joins Wi-Fi, the firmware would call something like:

#include <ESPmDNS.h>

if (MDNS.begin("cydnet")) {             // answers to cydnet.local
  MDNS.addService("http", "tcp", 80);   // advertises the web server
}

Pros and cons

  • + Works without touching the router or adding hardware.
  • + Follows the CYD automatically if its IP address changes.
  • − The address must end in .local; plain cydnet won’t use mDNS.
  • − Some older Android phones and some Android browsers don’t resolve .local names.
  • − Doesn’t cross networks: guest Wi-Fi, separate VLANs, or “AP/client isolation” will block it.

5. Option 2: Device hostname + router DNS Plain name, router-dependent

When the CYD asks the router for an IP address (DHCP), it can include a hostname. Many home routers (and most that run OpenWrt, DD-WRT, pfSense, OPNsense, Ubiquiti, or Asus firmware) add those names to their own DNS, so every device on the network can look up cydnet. Some routers only answer for a local suffix such as cydnet.lan or cydnet.home.

What it would take

WiFi.setHostname("cydnet");   // must be called before WiFi.begin()
WiFi.begin(ssid, password);

Alternatively, many router admin pages let you rename a connected device directly, with no firmware change at all.

How to find out if your router supports it

  • Open the router’s admin page and look at the list of connected (DHCP) clients. If you see device names there, the router knows hostnames.
  • From a PC, run nslookup <some-device-name> for a device listed there. If you get its IP back, the router resolves hostnames.

Pros and cons

  • + Plain http://cydnet/ on every device, including phones, with no extra hardware.
  • + Follows the CYD if its IP changes.
  • − Entirely up to the router; many internet-provider routers ignore hostnames.

6. Option 3: NetBIOS (Windows only) Plain name on PCs

NetBIOS name service is an old Windows networking method that broadcasts “who is CYDNET?” on the local network. The ESP32 Arduino core includes a NetBIOS library:

#include <NetBIOS.h>

NBNS.begin("CYDNET");   // max 15 characters
  • + Plain http://cydnet/ on Windows PCs with no router setup.
  • − Phones and Macs don’t use it.
  • − Windows is gradually disabling NetBIOS on some networks; treat it as a convenience, not the main method.

7. Option 4: A local DNS server Most reliable, needs equipment

A DNS server you control holds a record saying cydnet → 192.168.4.27. Every device that uses that server can look the name up. The CYD itself doesn’t need any changes.

Where the DNS server can live

Your router (check this first)
Some routers have a “Local DNS”, “Static DNS”, “DNS host mapping”, or “Hostnames” page where you can add a name and IP. If yours does, this is the simplest form of this option.
Pi-hole on a Raspberry Pi
A popular ad-blocking DNS server with a web page under Local DNS → DNS Records for adding cydnet. It needs an always-on Pi.
dnsmasq or Unbound
Lightweight DNS servers for Linux. In dnsmasq, a single line does it: address=/cydnet/192.168.4.27.
Windows Server DNS, or a DNS tool on an always-on PC
Works, but the PC must stay on or nobody can resolve any name, including internet sites.

The important second step

Adding the record isn’t enough: devices must actually use that DNS server. Usually you change the router’s DHCP settings so it hands out the DNS server’s address to every device. If the router itself is the DNS server, this is already true.

Avoid single points of failure. If the DNS server is a Pi or PC that goes offline, every device on the network loses internet name lookups, not just cydnet. Give the DNS server a reserved IP and a reliable power supply.

Pros and cons

  • + Plain http://cydnet/ (or any name you like) on every device.
  • + No firmware changes.
  • − Needs a router feature or an always-on device.
  • − Points at a fixed IP, so the CYD’s IP must be reserved (see below).

8. Option 5: The hosts file Quick test on one PC

Every computer has a hosts file that’s checked before DNS. Adding one line makes the name work on that computer only.

  • Windows: open Notepad as Administrator, then open C:\Windows\System32\drivers\etc\hosts.
  • Mac/Linux: sudo nano /etc/hosts

Add:

192.168.4.27    cydnet

Good for trying the name out today on your own PC. Not practical for a crew’s phones, since phones don’t let you edit this file.

9. Do this regardless: reserve the IP address

Routers hand out addresses that can change after a restart or power outage. A DHCP reservation (also called “static lease” or “address reservation”) tells the router to always give the CYD 192.168.4.27.

  • Options 4 and 5 require this, because they point at a fixed IP.
  • Options 1–3 follow the CYD automatically, but a reservation still keeps bookmarks to the IP working.

In the router’s admin page, look under DHCP, LAN, or Address Reservation and pick the CYD from the client list (it’s identified by its MAC address).

11. How to test a name

From a Windows PowerShell or Command Prompt window:

ping cydnet            # tries hosts file, DNS, LLMNR, NetBIOS
ping cydnet.local      # tries mDNS
nslookup cydnet        # asks DNS only; shows which DNS server answered
ipconfig /all          # look for "DNS Servers" to see which server this PC uses
ipconfig /flushdns     # clear cached lookups after changing a record

On a phone, simply open http://cydnet/ and http://cydnet.local/ in the browser. If you change a DNS record, toggling Wi-Fi off and on clears the phone’s cache.

ping succeeding but nslookup failing means the name was found by mDNS, NetBIOS, or the hosts file, not by DNS — so phones may not see it.

12. Recommendation for CrewBoard

  1. Reserve 192.168.4.27 for the CYD in the router.
  2. Check the router for a local DNS / host-mapping page. If it has one, add cydnet → 192.168.4.27 and you’re done — no code needed.
  3. If not, a small firmware update would:
    • add a "hostname": "CYDNet" setting to config.json;
    • set the Wi-Fi hostname, so routers that support Option 2 give everyone http://cydnet/;
    • start mDNS, so http://cydnet.local/ works on phones and computers;
    • start NetBIOS, so http://cydnet/ works on Windows PCs;
    • show the name on the CYD screen beside the IP address.
    About 15 lines, using libraries already included with the ESP32 Arduino core.
  4. To try a name today on your own PC, use the hosts file (Option 5).

13. Glossary

DNS (Domain Name System)
The service that turns names into IP addresses.
DNS record (A record)
One entry in a DNS server mapping a name to an IPv4 address.
DHCP
How the router hands out IP addresses (and the DNS server to use) to devices that join the network.
DHCP reservation / static lease
A router setting that always gives a particular device the same IP address.
Hostname
The name a device calls itself, which it can share with the router.
mDNS / Bonjour
Devices answering for their own .local names via multicast on the local network.
NetBIOS name service / LLMNR
Older Windows methods for resolving single-word names by broadcasting on the local network.
Hosts file
A text file on each computer that overrides DNS for specific names.
Pi-hole
A DNS server, usually on a Raspberry Pi, with a web interface and local DNS records.
VLAN / client isolation
Router features that separate devices into groups that can’t see each other.
